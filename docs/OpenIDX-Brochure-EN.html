Four identity products.
One platform. One database.

OpenIDX unifies identity management (IAM), governance (IGA), privileged access (PAM), and a zero-trust network plane (ZTNA) — work you normally buy as four separate products — into a single self-hostable platform over one PostgreSQL database. It is built to replace a stack of Microsoft Entra ID + Okta + SailPoint + CyberArk + Zscaler at 70–80% below their stacked per-user pricing.

Deployment roadmap

Phases run independently so value arrives early. A typical pilot is 30–45 days.

0
Discovery & scope (1–2 wks) — map the existing stack, choose the first value point (SSO+MFA or PAM access), define success criteria.
1
Foundation (2–4 wks) — self-host (Docker/K8s), directory sync (LDAP/AD/Azure AD), first 2–3 apps on SSO + MFA, audit/SIEM/backup.
2
Privileged access (2–4 wks) — critical servers into the vault, SSH/RDP/VNC brokering + recording, rotation, JIT + approvals.
3
Zero-trust network (3–6 wks) — OpenZiti overlay, critical services go "dark" (ports close), clientless/agent + posture, PAM targets moved onto the overlay.
4
Governance & compliance (parallel) — access reviews, SoD, HR-driven JML, kill switch + Access 360, compliance reports, pentest.
5
Go-live & scale — pilot → production, staged rollout, support/SLA, paid add-ons.

Proven capabilities (code-verified)

Identity & Access

  • OAuth 2.0/OIDC (PKCE, refresh rotation, token exchange, JWKS rotation)
  • SAML 2.0 IdP (XML-DSig, SP metadata, SLO)
  • MFA: TOTP, WebAuthn/passkey, push, OTP + adaptive risk/step-up
  • LDAP/AD/Azure AD sync, SCIM 2.0 (filter, PATCH)

Privileged Access

  • Envelope-encrypted vault + KEK rotation
  • Rotation: SSH, AWS IAM, GCP SA, Postgres, MySQL, LDAP
  • Guacamole SSH/RDP/VNC + credential injection, recording, legal hold
  • Privileged sessions over OpenZiti — no inbound port on the target

Governance

  • Access reviews + certification (revocation enforced)
  • SoD preventive, fail-closed; JIT + automatic expiry
  • RBAC/ABAC/OPA; HR-driven Joiner/Mover/Leaver

Zero-Trust Network & Platform

  • Identity-driven "dark" services, clientless BrowZer
  • Desktop (signed Windows) + Android agent, posture
  • Multi-tenant FORCE row-level security (CI-enforced)
  • HMAC hash-chained audit + Elasticsearch, SIEM, Prometheus/OTel
