# Register for scripts/check-docs-drift.sh.
#
# The guard fails when a document cites a repo path that is not there, because
# a path in backticks reads as a fact and a reader who cannot find it assumes
# they are looking in the wrong place. This file records the citations that are
# correct anyway, and why.
#
# Format, one per line:
#   allow <repo-path>  <reason>     a path that is cited and does not exist
#   skip  <glob>       <reason>     a document exempt from the check entirely
#
# Two rules keep this register from becoming the place drift hides:
#   - Every entry needs a reason. A bare path is a parse error.
#   - An `allow` whose path COMES BACK, or that no document cites any more,
#     fails the guard. A waiver nobody rechecks is the same defect one level up.
#
# `skip` is for documents that are records of a moment -- a dated audit, a
# merged plan, a shipped design. Making those track the tree would mean
# rewriting history; the banner at the top is what keeps them safe, and the
# reason below says so. Prefer `allow` over `skip` whenever the document is
# still live.
