### Security
- **The agent release key is used only by a release build, behind a release-signing environment.** The Windows build workflow handed the code-signing certificate to every run of its build job, so a same-repository pull request was built and Authenticode-signed with the release key by whatever that pull request put in the workflow's path. The certificate now reaches the job only on an `agent-v*` tag or a dispatch with `release=true`; a push or a pull request builds an unsigned MSI. A new `release-gate` job declares the `release-signing` GitHub environment and stands in front of every signed build, so a required reviewer or wait timer set on that environment holds each release. The maintainer adds the environment's protection rules in the repository settings (#1183).
