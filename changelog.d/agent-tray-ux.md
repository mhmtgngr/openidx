### Added
- **Tray: "Open my apps".** While signed in, the Windows tray opens the end-user portal (`/my-network`) on the configured server.
- **Tray: clearer Network status.** One line reads Connected, Connecting, Off or Error with a short reason; when the tunnel is off by policy the submenu says IT turns it on.
- **Tray: Turkish.** Every tray label, tooltip and notification comes from one string table; Turkish is used when the Windows UI language (`GetUserDefaultUILanguage`) is Turkish, English otherwise.
