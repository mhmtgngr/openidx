### Added
- **The agent API has a written contract.** `api/agent-v1.yaml` (OpenAPI 3.0) describes every route the endpoint agents call on the access service, with each field spelled as the server's Go JSON tag spells it, both shapes the server accepts where two exist (the nested and the flat posture result, the tunnel's service names and the older object form, marked deprecated), the device-key signature headers and every error code. The contract states the compatibility rule: an agent must work against a server up to two minor versions newer, and the server keeps accepting the previous wire shape for one release after a change. `go test ./internal/access -run TestAgentAPIContract` holds the file and the Go types to each other in both directions, so a field renamed on one side only fails the build. [CONTRIBUTING.md](CONTRIBUTING.md) says how a wire-shape change is made.
