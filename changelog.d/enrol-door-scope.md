### Security
- **The enrolment door asks for a token issued for device enrolment, and honours revocation.** `POST /api/v1/access/enroll`, the one route that stays public when the platform goes dark, accepted any verified access token of the organization, a console session token included, and refreshed the user's overlay enrolment token to a seven-day life for it. It now requires the `agent.enroll` scope (403 `insufficient_scope`), refuses a token the kill switch, a device revoke or a leaver's disable has cut (401 `token_revoked`, read from the same revocation cutoff `/oauth/userinfo` reads; 503 while the revocation store cannot answer), and mints the enrolment JWT with a fifteen-minute life. No shipped client calls this route; an integration that does needs a token from a client granted `agent.enroll`.
