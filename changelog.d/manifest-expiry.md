### Security
- **The agent's update manifest expires.** `latest.json` now carries `expires`, 90 days after the release, and `signature_v2`, a signature that covers it beside the fields `signature` already covered. The signature said who wrote the manifest, not that it was still the newest: a copy of any manifest ever signed was as good as the latest one, so a stale mirror, a proxy or a captured response could hide every later release from the fleet for as long as it liked. Agents from this release on verify `signature_v2` and refuse a manifest with `signature` alone, with no `expires`, past it, or with one more than a year ahead; agents built earlier keep verifying `signature`, which the release still produces. A channel not renewed by an agent release within 90 days stops updating, which is the safe direction, and the agent's log says why. An operator signing their own channel adds `expires` and `signature_v2` as `agent/packaging/wix/README.md` describes.
