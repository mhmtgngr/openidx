### Changed
- **Changelog entries are fragments.** A pull request now describes its user-facing change in its own `changelog.d/<slug>.md` instead of `CHANGELOG.md`'s `[Unreleased]` section, so parallel pull requests no longer conflict there. `scripts/changelog-assemble.sh X.Y.Z` folds the fragments into the release section when a version is cut (`docs/RELEASING.md`), and CI refuses a fragment it could not assemble.
- **Database-backed tests read one variable.** `TEST_POSTGRES_DSN` is the Postgres a test may use; `OPENIDX_TEST_DATABASE_URL` still works as a deprecated alias. Suites that build the whole schema now create and drop a database of their own on that server rather than dropping its `public` schema, so one server can serve several packages at once.

### Fixed
- **CI's Go cache restores again.** setup-go v5 installed the `go` line of `go.mod` (1.26.0), its own `go env` then downloaded the pinned `toolchain` into the module cache, and restoring a cache that already held that toolchain failed with `tar: Cannot open: File exists`, so jobs ran cold, or failed outright when the download did. setup-go v6 installs the pinned toolchain directly, and the second `actions/cache` over the same paths is gone.
